Instalar Claude Code, rtk y caveman

Los tres pasos que dejan la terminal lista: Claude Code para trabajar, rtk para gastar menos, y caveman para que las respuestas sean cortas.

1. Claude Code

Mac

curl -fsSL https://claude.ai/install.sh | bash

No necesita Node.js. Deja el programa en ~/.local/bin/claude.

Windows (PowerShell)

irm https://claude.ai/install.ps1 | iex

Si PowerShell no deja ejecutarlo:
Set-ExecutionPolicy -Scope Process Bypass

Después, en cualquier carpeta:

claude

La primera vez abre el navegador para iniciar sesión con tu cuenta de Claude. Para salir de la conversación: /exit.

Comprobar que quedó: claude --version

2. rtk — gastar menos en cada tarea

rtk se mete entre Claude y la terminal: recorta la salida de los comandos antes de que Claude la lea. En operaciones de desarrollo ahorra entre 60% y 90% de consumo.

Instalar en Mac

brew install rtk-ai/tap/rtk
rtk --version

Si Homebrew avisa que el tap no es de confianza:

brew trust rtk-ai/tap

Sin Homebrew, el binario suelto:

curl -fsSL https://github.com/rtk-ai/rtk/releases/latest/download/rtk-aarch64-apple-darwin.tar.gz -o rtk.tar.gz
tar -xzf rtk.tar.gz && mkdir -p ~/.local/bin && mv rtk ~/.local/bin/ && chmod +x ~/.local/bin/rtk

En Mac con procesador Intel, cambia aarch64 por x86_64.

Instalar en Windows

Invoke-WebRequest https://github.com/rtk-ai/rtk/releases/latest/download/rtk-x86_64-pc-windows-msvc.zip -OutFile rtk.zip
Expand-Archive rtk.zip -DestinationPath "$env:LOCALAPPDATA\rtk"

Y agregar esa carpeta al PATH del usuario.

Conectarlo a Claude Code

rtk trabaja mediante un hook: una instrucción en la configuración de Claude que reescribe los comandos solos. Se agrega a ~/.claude/settings.json (en Windows, %USERPROFILE%\.claude\settings.json):

{
  "hooks": {
    "PreToolUse": [
      { "matcher": "Bash",
        "hooks": [ { "type": "command", "command": "rtk hook claude" } ] }
    ]
  }
}
Comprobar que trabaja: rtk gain muestra cuánto se ahorró. Si dice «command not found», rtk no quedó en el PATH.
Ojo con el nombre. Existe otro programa llamado rtk (Rust Type Kit). Si rtk gain falla, tienes el equivocado: revisa con which -a rtk.

3. caveman — respuestas cortas

caveman es un plugin: hace que Claude conteste al grano, sin relleno ni cortesías, conservando el contenido técnico. Se instala desde dentro de Claude Code.

  1. Abre la terminal y escribe claude.
  2. Agrega el catálogo de plugins:
    /plugin marketplace add JuliusBrussee/caveman
  3. Instala el plugin:
    /plugin install caveman@caveman
  4. Sal y vuelve a entrar (/exit y otra vez claude) para que cargue.
  5. Pruébalo: escribe /caveman. Para apagarlo, «modo normal» o «stop caveman».

Lo mismo se puede dejar escrito en settings.json, y así queda activo en cualquier computadora donde uses esa configuración:

{
  "enabledPlugins": { "caveman@caveman": true },
  "extraKnownMarketplaces": {
    "caveman": { "source": { "source": "github", "repo": "JuliusBrussee/caveman" } }
  }
}
Otros plugins útiles del catálogo oficial de Anthropic:
/plugin marketplace add anthropics/claude-plugins-official
/plugin install superpowers@claude-plugins-official

Comandos para verificar

ComandoQué debe responder
claude --versionEl número de versión de Claude Code
rtk --versionrtk 0.38.0 o más nuevo
rtk gainEl resumen de ahorro; si falla, es el rtk equivocado
/plugin (dentro de Claude)La lista con caveman instalado
/cavemanActiva las respuestas cortas

El camino corto

En Mac, el instalador de Integral Marketing hace los tres pasos de una vez, más Git, Node, Python y las carpetas de trabajo:

bash mac/instalar-mac.sh

En Windows, el equivalente es windows\INSTALAR.bat del instalador de Claude Code.
